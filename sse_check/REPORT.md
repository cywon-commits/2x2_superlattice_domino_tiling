# SSE 루프 상한 점검: L=36 발표 결정의 재계산

## 요약
- 기존 `sse_h.py`는 루프 길이가 100·M을 넘으면 그 루프를 버린다. 허브(z=6)가 있는 N=12 계(`dice_L1_N12`)에서 β ≥ 30일 때 부호 평균이 1에서 벗어나는 것을 확인했다(상한을 없애면 부호 1.0, ED와 일치).
- 발표된 L=36 결정 4개를 결정론적 루프 코드 `sse_det.py`(별도 제공)로 같은 그래프·같은 β에서 다시 계산했다. 기존 값과의 차이는 모두 합친 오차의 2배 이내이다. 원고 수치는 유지한다.
- 계측판 `sse_h.py`(`code/sse_h3.py`)로 M/6 결정을 기존 프로토콜(β=36, 1200+6000 sweep) 그대로 돌렸을 때 상한을 넘은 루프는 0개, 부호는 항상 1이었다.

## 주의
- 12개 비교 중 11개에서 새 값이 낮다(개별로는 모두 오차 안). 가장 큰 편차(−2.49σ)는 허브가 있는 2M/3 자기장 모드이며, 시드 2개뿐이다.
- 기존 계측판(`l36.py`, 시드 1·2, orig/nocap): M/6에서 상한 초과 루프 0, 중단 루프 0, 부호 최솟값 1, 최장 루프 1.6–1.7×10⁶ 스텝. orig는 e = −0.670314(139), −0.670554(133)로 발표값 −0.670462(102)와 일치.
- 기존 실행 기록(`ref/*.log`)에는 부호·버려진 루프 수가 남아 있지 않아, 기록만으로는 확인할 수 없다.
- 점검 범위는 L=36 결정 4개다. 부록 A의 L=18, 24 점과 N≤36 점은 재계산하지 않았다.
